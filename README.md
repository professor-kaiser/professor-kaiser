## What I build

### 🔢 Finding better decisions under constraints

**PyVertex**

A solver for **linear and integer optimization problems**.

I work on:
- simplex-based optimization
- integer programming
- Gomory cuts
- pivot strategies
- solver algorithms and testing

🔗 [PyVertex](https://github.com/professor-kaiser/vertex)

---

### 🤖 Making a robot reach a target

**6-DOF Robot**

A robotic arm project focused on the problem:

> Given a desired position, how can we determine the joint movements required to reach it?

The project explores:
- forward kinematics
- inverse kinematics
- Jacobians
- numerical methods
- automatic differentiation

---

### 👁️ Recovering useful information from images

**Super-Resolution**

I experiment with neural networks that reconstruct **higher-resolution images from low-resolution inputs**.

The goal is not simply to make an image larger, but to learn how to **recover visual details that are missing or degraded**.
